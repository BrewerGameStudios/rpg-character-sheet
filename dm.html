How the Digital Library Works

Adding a book

Only a title is required. The "link" field is optional — fill it in only if the book is already hosted somewhere online (Google Drive, Dropbox, etc.). If it's just a file on your own computer, leave it blank; the book still works fine without one.

Making it searchable

Pick the PDF file when adding or editing a book, and the browser reads its text right there and indexes it for search — the file itself is never uploaded anywhere, only the extracted text is. Picking the file also remembers a copy of it in this browser, on this device, which is what lets a search result open straight to the right page later (more on that below).

The badge on each book tells you where it stands: Searchable means it's been indexed, Not indexed means it hasn't yet — you can always go back and pick the file later to add search.

Searching

Type in the search box to search the actual text of every indexed book, not just titles. Each matching book shows one or more highlighted excerpts of the surrounding text so you can see the match in context — scroll inside a book's card if it has more than a few.

Clicking a search result

Clicking a highlighted excerpt tries three things, in order, and does whichever one actually applies to that book:

  • Opens right inside the app, jumped to that exact page, if this browser has that book's file remembered (see above).
  • Opens your online link at that page in a new tab, if the book has one but wasn't indexed on this device.
  • Just tells you the page number if neither is available, so you know where to look in your own copy.

The "remembered" file only lives in this browser on this device — it won't follow you to a different computer or browser. Pick the file again there to enable in-app opening on that device too.

Inside the viewer

📂 Save Local Copy

A book's "link" field points to wherever the file actually lives online — it doesn't store the file itself. This button does: it remembers the file's own bytes right in THIS browser, on THIS device, so a search result here opens it directly instead of falling back to that external link. It's per-device — opening the same book on a different computer or browser needs its own click of this button there too. Clicking it again later just refreshes this device's stored copy.
